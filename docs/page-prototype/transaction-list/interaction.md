# 账单列表 - 交互逻辑

## 页面概述

账单列表是历史交易记录的浏览入口，支持搜索、筛选、分组查看和详情查看。

---

## 4.2.1 搜索栏

### 布局

```
┌─────────────────────────────────────────┐
│  🔍 搜索交易...                    ✕    │
└─────────────────────────────────────────┘
```

- 位置：页面顶部，固定
- 高度：44px
- 左侧搜索图标，右侧清除按钮（输入内容后显示）

### 交互行为

| 操作 | 响应 | 详情 |
|------|------|------|
| 点击搜索框 | 聚焦键盘，显示取消按钮 | 搜索框获得焦点 |
| 输入文字 | 实时搜索（防抖300ms） | 搜索描述、分类名、备注 |
| 点击清除(✕) | 清空搜索内容，恢复完整列表 | 输入框保留焦点 |
| 点击取消 | 退出搜索模式，收起键盘 | 清空内容，恢复列表 |
| 键盘确认(Search) | 执行搜索，收起键盘 | 保持搜索结果 |

### 搜索规则

- 模糊匹配：交易描述、分类名称、备注
- 不区分大小写
- 搜索结果保持分组结构
- 无结果时显示"未找到相关记录"

---

## 4.2.2 筛选栏

### 布局

```
┌─────────────────────────────────────────┐
│  [全部] [支出] [收入] [2025年1月 ▼]     │
└─────────────────────────────────────────┘
```

- 位置：搜索栏下方
- 水平滚动，标签形式

### 交互行为

| 操作 | 响应 | 详情 |
|------|------|------|
| 点击"全部" | 显示所有交易 | 默认选中状态 |
| 点击"支出" | 仅显示支出交易 | 排除收入类型 |
| 点击"收入" | 仅显示收入交易 | 排除支出类型 |
| 点击月份选择 | 弹出月份选择器 | BottomSheet形式 |
| 月份选择确认 | 按所选月份筛选 | 更新列表 |

### 筛选联动

- 搜索 + 筛选条件叠加生效
- 筛选变更后列表平滑刷新
- 筛选状态在页面生命周期内保持

## 4.2.4 账单详情

### 页面结构

```
┌─────────────────────────────────────────┐
│  ← 账单详情                      ✏️ 编辑│
├─────────────────────────────────────────┤
│                                         │
│         🍜                              │
│       餐饮 > 午餐                       │
│                                         │
│       -¥25.00                           │
│                                         │
├─────────────────────────────────────────┤
│  描述         午饭拉面                  │
│  ─────────────────────────────────────  │
│  时间         2025-06-02 12:30          │
│  ─────────────────────────────────────  │
│  分类         餐饮 > 午餐               │
│  ─────────────────────────────────────  │
│  备注         公司楼下兰州拉面           │
│  ─────────────────────────────────────  │
│  AI解析       由AI自动识别              │
│  ─────────────────────────────────────  │
│  创建时间     2025-06-02 12:31          │
│                                         │

```

### 交互行为

| 操作 | 响应 | 详情 |
|------|------|------|
| 点击返回(←) | 返回列表页 | pop转场 |
| 点击编辑(✏️) | 进入编辑模式 | 预填表单 |
| 点击删除记录 | 二次确认弹窗 | 确认后删除并返回列表 |
| 长按描述/备注 | 复制到剪贴板 | 显示"已复制"提示 |
