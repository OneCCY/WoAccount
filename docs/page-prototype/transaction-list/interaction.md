# 账单页 - 交互逻辑

## 页面概述

账单页是左Tab，展示所有交易记录，支持日/周/月三种视图切换。

---

## 7.1.1 页面布局

```
┌─────────────────────────────┐
│  [日][周][月]  ‹ 周期导航 › │  ← 视图切换栏
├─────────────────────────────┤
│  🔍 搜索账单...             │  ← 搜索栏
├─────────────────────────────┤
│    可滚动内容区             │
│    - 日视图: 当日交易列表   │
│    - 周视图: 7天卡片+列表   │
│    - 月视图: 日历网格       │
│    - 洞察卡片               │
└─────────────────────────────┘
```

---

## 7.1.2 视图切换

### 交互行为

| 操作 | 响应 | 详情 |
|------|------|------|
| 点击"日" | 切换到日视图 | 当日交易列表 |
| 点击"周" | 切换到周视图 | 7天卡片+分组列表 |
| 点击"月" | 切换到月视图 | 日历网格 |
| 点击‹ | 切换到上一周期 | 日→昨天，周→上周，月→上月 |
| 点击› | 切换到下一周期 | 不超过当前 |

---

## 7.1.3 搜索 + 预算入口

### 布局

```
┌─────────────────────────────────────┐
│  🔍 搜索账单...               💰   │
└─────────────────────────────────────┘
```

- 搜索框占满左侧
- 右侧💰按钮为预算管理入口

### 交互行为

| 操作 | 响应 | 详情 |
|------|------|------|
| 点击搜索框 | 聚焦键盘 | 搜索模式 |
| 输入文字 | 实时搜索(防抖300ms) | 搜索描述、分类 |
| 清空输入 | 恢复完整列表 | 退出搜索模式 |
| 点击💰 | 进入预算管理页 | 跳转到预算管理 |

---

## 7.1.4 左滑删除

### 交互行为

账单列表中的每条记录支持左滑操作，显示删除按钮。

| 操作 | 响应 | 详情 |
|------|------|------|
| 左滑记录 | 显示红色"删除"按钮 | 滑动距离 > 60px 触发 |
| 点击"删除" | 二次确认弹窗 | 确认后动画移除该条记录 |
| 右滑或点击空白 | 收回删除按钮 | 关闭已滑开的项 |
| 滑动距离不足 | 回弹 | 不显示删除按钮 |

### 删除确认

```
┌─────────────────────────────────────┐
│                                     │
│      确认删除这条记录？             │
│                                     │
│   [取消]           [确认]           │
└─────────────────────────────────────┘
```

### 删除动画

确认删除后，该条记录高度收缩 + 渐隐，300ms 后从 DOM 移除。

## 7.1.5 日视图

### 交互行为

| 操作 | 响应 | 详情 |
|------|------|------|
| 左滑页面区域 | 切换到下一天 | 同点击› |

| 点击列表项 | 进入账单详情 | push转场 |

| 左滑页面区域 | 切换到下一周 | 同点击› |
| 右滑页面区域 | 切换到上一周 | 同点击‹ |

| 左滑列表项 | 显示删除按钮 | 见 7.1.4 |

## 7.1.7 月视图

### 交互行为

| 操作 | 响应 | 详情 |
|------|------|------|
| 点击日期格 | 切换到日视图 | 显示该天交易 |
| 左滑日历 | 切换到下月 | 同点击› |
| 右滑日历 | 切换到上月 | 同点击‹ |

---

## 7.1.8 账单详情

### 交互行为

| 操作 | 响应 | 详情 |
|------|------|------|
| 点击返回(←) | 返回列表页 | pop转场 |
| 点击编辑(✏️) | 进入编辑模式 | 预填表单 |
| 点击删除记录 | 二次确认弹窗 | 确认后删除并返回 |
| 长按描述/备注 | 复制到剪贴板 | 显示"已复制"提示 |

## 页面间导航

```
账单页 ──点击──→ 账单详情
  │                  ├──编辑──→ 编辑页
  │                  └──删除──→ 返回列表
  │
  ├──切换日/周/月──→ 刷新视图
  ├──搜索──→ 筛选列表
  ├──点击💰──→ 预算管理页
  ├──点击日期卡片──→ 切换到日视图
  └──左滑记录──→ 显示删除按钮──→ 确认删除
```
