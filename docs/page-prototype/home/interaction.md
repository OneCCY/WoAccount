# 记账首页 - 交互逻辑

## 页面概述

记账首页是核心入口，支持周视图和月视图切换，上方为交易数据区（可滚动），下方为固定记账输入栏。

---

## 4.1.1 页面布局

```
┌─────────────────────────────┐
│         状态栏              │
├─────────────────────────────┤
│  [周][月]    ‹ 周/月导航 ›  │  ← 视图切换栏
├─────────────────────────────┤
│                             │
│    可滚动内容区             │
│    - 周视图: 按日分组列表   │
│    - 月视图: 日历网格       │
│    - 洞察卡片               │
│    - AI助手入口             │
│                             │
├─────────────────────────────┤
│    记账输入栏 (固定)        │
├─────────────────────────────┤
│    底部导航                 │
└─────────────────────────────┘
```

---

## 4.1.2 视图切换

### 布局

```
┌──────────────────────────────────────┐
│  [周] [月]         ‹ 6月2日-6月8日 › │
└──────────────────────────────────────┘
```

- 左侧：周/月切换按钮组（Segmented Control）
- 右侧：周期导航（左箭头 + 当前周期 + 右箭头）

### 交互行为

| 操作 | 响应 | 详情 |
|------|------|------|
| 点击"周" | 切换到周视图 | 列表按日分组展示，默认当前周 |
| 点击"月" | 切换到月视图 | 日历网格展示，默认当前月 |
| 点击左箭头(‹) | 切换到上一周期 | 周视图→上周，月视图→上月 |
| 点击右箭头(›) | 切换到下一周期 | 周视图→下周，月视图→下月（不超过当前） |

## 4.1.5 记账输入栏

### 布局

```
┌───┬─────────────────────────┬───────┐
│ ➕ │ 输入消费描述...          │  📷  │
└───┴─────────────────────────┴───────┘
```

- 位置：固定在底部导航上方
- 高度：约 60px
- 背景：白色，顶部有分割线

### 元素规格

| 位置 | 元素 | 尺寸 | 功能 |
|------|------|------|------|
| 左侧 | ➕ 手动记账按钮 | 44x44px | 点击打开手动记账表单 |
| 中间 | 文本输入框 | flex:1, h44px | 输入消费描述，AI自动解析 |
| 右侧 | 📷 拍照按钮 | 44x44px | 点击调用相机/相册识别小票 |

### 交互行为

| 操作 | 响应 | 详情 |
|------|------|------|
| 点击➕ | 打开手动记账BottomSheet | 金额+分类+日期表单 |
| 点击输入框 | 聚焦键盘 | 输入框获得焦点 |
| 输入内容 | 实时显示 | 支持自然语言描述 |
| 键盘确认(Enter) | 提交记账 | AI解析 → 确认卡片 |
| 点击📷 | 弹出选择菜单 | 拍照 / 从相册选择 |
| 输入为空时提交 | 提示输入 | 输入框抖动动画 |

## 4.1.6 语音输入（长按记账Tab）

### 触发方式

长按底部导航"记账"Tab 500ms 触发。

### 状态流程

```
按下 → 等待500ms → 触发语音 → 录音中
                                    │
                    ┌───────────────┼───────────────┐
                    ▼               ▼               ▼
                 松开            左上滑           右上滑
                 发送            取消            转文字
```

### 交互详情

| 操作 | 手势 | 响应 | 触觉反馈 |
|------|------|------|----------|
| 按住500ms | 按住不动 | 显示语音浮层，开始录音 | 轻微震动 |
| 松开 | 原地松开 | 发送语音，AI解析转文字 | 无 |
| 左上滑 | 按住后向左上滑动 | 取消录音，关闭浮层 | 无 |
| 右上滑 | 按住后向右上滑动 | 语音转文字，填入输入框 | 无 |

## 页面间导航

```
首页 ──点击──→ 账单详情（列表项）
 │
 ├──点击──→ 手动记账（BottomSheet）
 │              └──确认──→ 保存并刷新列表
 │
 ├──点击──→ 拍照识别（相机/相册）
 │              └──识别──→ AI解析确认卡片
 │
 ├──点击──→ AI助手（跳转我的页面）
 │
 ├──输入+提交──→ AI解析确认卡片
 │                  └──确认──→ 保存并刷新列表
 │
 ├──长按Tab──→ 语音输入浮层
 │                  ├──松开──→ AI解析确认卡片
 │                  ├──左滑──→ 取消
 │                  └──右滑──→ 转文字填入输入框
 │
 ├──点击日期格(月视图)──→ 该日交易明细BottomSheet
 │
 └──切换周/月──→ 刷新对应视图数据
```
