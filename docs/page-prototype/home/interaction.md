# 记账页 - 交互逻辑

## 页面概述

记账页是中Tab核心入口，页面极度聚焦：顶部AI入口，底部固定输入栏，中间留白。

设计原则：**记账页面只做一件事——让用户快速记下一笔。**

## 8.1.3 记账输入栏

### 元素

| 位置 | 元素 | 功能 |
|------|------|------|
| 左侧 | ➕ 按钮 | 打开手动记账表单 |
| 中间 | 文本输入框 | 输入消费描述，Enter提交 |
| 右侧 | 📷 按钮 | 拍照识别小票 |

### 交互行为

| 操作 | 响应 | 详情 |
|------|------|------|
| 点击➕ | 进入手动记账全屏页面 | 支出/收入/其他 + 分类 + 数字键盘 |
| 点击输入框 | 聚焦键盘 | 输入框获得焦点 |
| 输入内容 + Enter | 提交记账 | AI解析 → 确认卡片 |
| 点击📷 | 弹出选择菜单 | 拍照 / 从相册选择 |
| 输入为空 + Enter | 无响应 | 不提交 |

## 8.1.4 手动记账页面

点击➕进入全屏记账页面，上方选择类型和分类，下方数字键盘输入金额。

### 页面布局

```
┌─────────────────────────────────────┐
│  首页                       当前账本 │
├─────────────────────────────────────┤
│    [支出]      [收入]      [其他]   │
├─────────────────────────────────────┤
│  🍜    🚗    🛒    🏠    🎮        │
│  餐饮  交通  购物  住房  娱乐       │  ← 一级分类(5列)
│  📚    💊    👤    🐱    💰⚙       │  ← 右下角+展开二级
│  教育  医疗  社交  宠物  其他       │  ← ⚙管理分类
├─────────────────────────────────────┤
│  餐饮/吃好的                        │  ← 已选分类显示(选择后出现)
├─────────────────────────────────────┤
│  添加备注...          0.00          │
├─────────────────────────────────────┤
│  1     2     3     今天             │  ← 点击弹出日历
│  4     5     6     +                │  ← 计算器
│  7     8     9     -                │
│  .     0     ⌫    完成              │
└─────────────────────────────────────┘
```

### 分类区域交互

| 操作 | 响应 | 详情 |
|------|------|------|
| 点击一级分类 | 选中该分类 | 高亮显示，下方显示已选分类 |
| 点击分类右下角"+" | 弹出二级分类浮层 | 覆盖在父级分类界面上层 |
| 点击二级分类 | 选中子分类 | 记录为"父/子"格式，下方显示"餐饮/吃好的" |
| 点击二级浮层"✕" | 关闭浮层 | - |
| 点击分类右下角"⚙" | 进入分类管理 | 创建或管理分类 |
| 左右滑动分类区域 | 切换页面（如分类过多翻页） | 分页指示器跟随 |
| 切换类型（支出/收入/其他） | 重置分类选择 | 隐藏已选分类显示 |

### 二级分类浮层

```
┌─────────────────────────────────────┐
│  餐饮                           ✕  │  ← 标题+关闭
├─────────────────────────────────────┤
│  🥐    🍱    🍲    ☕    🍪        │  ← 二级分类(5列)
│  早餐  午餐  晚餐  饮料  零食       │
└─────────────────────────────────────┘
```

| 操作 | 响应 | 详情 |
|------|------|------|
| 点击"+"按钮 | 弹出浮层 | 覆盖在父级分类上方，半透明白色背景 |
| 点击二级分类 | 选中并关闭 | 记录"餐饮/午餐"格式，显示在下方 |
| 点击"✕" | 关闭浮层 | 不选择任何子分类 |

### 数字键盘交互

| 操作 | 响应 | 详情 |
|------|------|------|
| 点击数字 | 输入金额 | 追加到末尾，限12位 |
| 点击⌫ | 删除最后一位 | 金额为0时不变 |
| 点击. | 输入小数点 | 仅一次，限2位小数 |
| 点击+/- | 计算器运算 | 追加运算符 |
| 点击"今天" | 弹出日历选择器 | 选择记账日期 |
| 点击"完成" | 提交记账 | 需已选分类且金额>0 |

### 日历选择器

| 操作 | 响应 | 详情 |
|------|------|------|
| 点击"今天"按钮 | 弹出当月日历 | 底部浮层 |
| 点击日期 | 选中该日期 | 高亮显示，关闭日历 |
| 点击"✕" | 关闭日历 | - |

## 8.1.5 语音输入（长按记账Tab）

### 交互详情

| 操作 | 手势 | 响应 |
|------|------|------|
| 按住500ms | 按住不动 | 显示语音浮层，开始录音 |
| 松开 | 原地松开 | 发送语音，AI解析 |
| 左上滑 | 按住后向左上滑动 | 取消录音 |
| 右上滑 | 按住后向右上滑动 | 语音转文字填入输入框 |

## 设计思考

记账页当前保持极简，后续可根据用户反馈考虑添加：

- **最近记录**：显示最近3-5笔，方便参考和重复记账
- **常用分类快捷入口**：高频分类一键记账
- **记账提醒**：定时提醒用户记账
- **消费趋势迷你图**：本周支出趋势小图表

以上功能需根据实际使用数据决定是否添加，避免过早增加复杂度。
