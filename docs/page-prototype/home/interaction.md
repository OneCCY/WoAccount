# 记账页 - 交互逻辑

## 页面概述

记账页是中Tab核心入口，专注记账输入和AI能力，不展示交易列表。

---

## 6.1.2 AI 助手入口

### 交互行为

| 操作 | 响应 | 详情 |
|------|------|------|
| 点击卡片 | 进入AI助手页面 | 跳转到我的→AI助手 |

---

## 6.1.3 快捷操作

### 布局

```
💡 快捷操作
┌────┐  ┌────┐  ┌────┐  ┌────┐
│ 🎤 │  │ 📷 │  │ ➕ │  │ 📊 │
│语音 │  │拍照 │  │手动 │  │统计 │
└────┘  └────┘  └────┘  └────┘
```

### 交互行为

| 按钮 | 操作 | 响应 |
|------|------|------|
| 🎤 语音 | 点击 | 触发语音录音浮层 |
| 📷 拍照 | 点击 | 调用相机/相册，识别小票 |
| ➕ 手动 | 点击 | 打开手动记账BottomSheet |
| 📊 统计 | 点击 | 跳转到我的→统计概览 |

---

## 6.1.4 今日洞察

### 交互行为

| 操作 | 响应 | 详情 |
|------|------|------|
| 点击卡片 | 展开详情 | 显示完整洞察分析 |
| 点击"详情" | 跳转统计页面 | 我的→统计 |
| 无洞察时 | 隐藏卡片 | 仅在有洞察时出现 |

---

## 6.1.6 记账输入栏

### 交互行为

| 操作 | 响应 | 详情 |
|------|------|------|
| 点击➕ | 打开手动记账BottomSheet | 金额+分类+日期表单 |
| 点击输入框 | 聚焦键盘 | 输入框获得焦点 |
| 输入内容 + Enter | 提交记账 | AI解析 → 确认卡片 |
| 点击📷 | 弹出选择菜单 | 拍照 / 从相册选择 |

---

## 6.1.7 语音输入（长按记账Tab）

### 交互详情

| 操作 | 手势 | 响应 |
|------|------|------|
| 按住500ms | 按住不动 | 显示语音浮层，开始录音 |
| 松开 | 原地松开 | 发送语音，AI解析 |
| 左上滑 | 按住后向左上滑动 | 取消录音 |
| 右上滑 | 按住后向右上滑动 | 语音转文字填入输入框 |
