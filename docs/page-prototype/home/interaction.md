# 记账页 - 交互逻辑

## 页面概述

记账页是中Tab核心入口，页面极度聚焦：顶部AI入口，底部固定输入栏，中间留白。

设计原则：**记账页面只做一件事——让用户快速记下一笔。**

## 8.1.3 记账输入栏

### 元素

| 位置 | 元素 | 功能 |
|------|------|------|
| 左侧 | ➕ 按钮 | 打开手动记账表单 |
| 中间 | 文本输入框 | 输入消费描述，Enter提交 |
| 右侧 | 📷 按钮 | 拍照识别小票 |

### 交互行为

| 操作 | 响应 | 详情 |
|------|------|------|
| 点击➕ | 进入手动记账全屏页面 | 支出/收入/其他 + 分类 + 数字键盘 |
| 点击输入框 | 聚焦键盘 | 输入框获得焦点 |
| 输入内容 + Enter | 提交记账 | AI解析 → 确认卡片 |
| 点击📷 | 弹出选择菜单 | 拍照 / 从相册选择 |
| 输入为空 + Enter | 无响应 | 不提交 |

## 8.1.4 手动记账页面

点击➕进入全屏记账页面，上方选择类型和分类，下方数字键盘输入金额。

### 页面布局

```
┌─────────────────────────────┐
│  取消                  保存  │
├─────────────────────────────┤
│    [支出]    [收入]    [其他]│
├─────────────────────────────┤
│                      ¥ 0    │
├─────────────────────────────┤
│  🍜   🚗   🛒   🏠   🎮    │
│  餐饮 交通 购物 住房 娱乐    │
│  📚   💊   👤   🐱   💰    │
│  教育 医疗 社交 宠物 其他    │
├─────────────────────────────┤
│  添加备注...        [今天]  │
├─────────────────────────────┤
│  1    2    3    ⌫           │
│  4    5    6    清空         │
│  7    8    9    记账         │
│  日期  0    .               │
└─────────────────────────────┘
```

### 交互行为

| 操作 | 响应 | 详情 |
|------|------|------|
| 点击"支出" | 切换到支出分类 | 默认选中 |
| 点击"收入" | 切换到收入分类 | 清空已选分类 |
| 点击"其他" | 切换到其他分类 | 清空已选分类 |
| 点击分类 | 选中该分类 | 高亮显示，"保存"按钮可点击 |
| 点击数字 | 输入金额 | 追加到金额末尾 |
| 点击⌫ | 删除最后一位 | 金额为0时不变 |
| 点击清空 | 金额重置为0 | - |
| 点击. | 输入小数点 | 仅可输入一次，限2位小数 |
| 点击"记账" | 提交记账 | 需已选分类且金额>0 |
| 点击"保存" | 提交记账 | 同"记账"按钮 |
| 点击"取消" | 返回上一页 | 不保存 |
| 点击"今天" | 选择日期 | 日期选择器 |
| 金额为0或未选分类 | "保存"按钮置灰 | 不可点击 |

## 8.1.5 语音输入（长按记账Tab）

### 交互详情

| 操作 | 手势 | 响应 |
|------|------|------|
| 按住500ms | 按住不动 | 显示语音浮层，开始录音 |
| 松开 | 原地松开 | 发送语音，AI解析 |
| 左上滑 | 按住后向左上滑动 | 取消录音 |
| 右上滑 | 按住后向右上滑动 | 语音转文字填入输入框 |

---

## 设计思考

记账页当前保持极简，后续可根据用户反馈考虑添加：

- **最近记录**：显示最近3-5笔，方便参考和重复记账
- **常用分类快捷入口**：高频分类一键记账
- **记账提醒**：定时提醒用户记账
- **消费趋势迷你图**：本周支出趋势小图表

以上功能需根据实际使用数据决定是否添加，避免过早增加复杂度。
