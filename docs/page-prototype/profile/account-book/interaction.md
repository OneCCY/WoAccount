# 我的账本 - 交互逻辑

## 页面概述

账本管理页面，支持创建、切换、管理多个独立账本。每个账本拥有独立的分类、预算和交易数据。

### 交互行为

| 操作 | 响应 | 详情 |
|------|------|------|

| 左滑列表项 | 显示操作按钮 | 设为默认(蓝) / 删除(红) |

## 5.1.6 账本切换机制

### 切换方式

| 方式 | 入口 | 说明 |
|------|------|------|
| 账本详情页 | "切换到此账本"按钮 | 进入详情后切换 |
| 账本列表 | 左滑 → "设为默认" | 快速切换默认 |
| 首页顶部 | 当前账本名（可点击） | 首页直接切换 |

### 切换后影响

```
切换账本
  │
  ├── 首页：今日消费列表更新
  ├── 周/月视图：统计数据更新
  ├── 统计：分类/趋势数据更新
  ├── AI助手：查询范围更新
  └── 设置：分类/预算显示对应账本
```

### 数据隔离

| 维度 | 隔离级别 | 说明 |
|------|----------|------|
| 交易记录 | 完全隔离 | 每个账本独立交易 |
| 分类体系 | 完全隔离 | 每个账本独立分类 |
| 预算设置 | 完全隔离 | 每个账本独立预算 |
| AI学习数据 | 跟随账本 | 每个账本独立学习 |
| 系统设置 | 共享 | 主题、密码锁等全局共享 |

## 5.1.7 家庭账本协作

### 成员管理

```
┌─────────────────────────────────────┐
│  成员管理                           │
│  ─────────────────────────────────  │
│  👤 我 (管理员)          移除       │
│  ─────────────────────────────────  │
│  👤 家人A (编辑者)       移除       │
│  ─────────────────────────────────  │
│  + 邀请成员                         │
└─────────────────────────────────────┘
```

### 权限级别

| 角色 | 权限 |
|------|------|
| 管理员 | 所有操作 + 成员管理 + 删除账本 |
| 编辑者 | 记账 + 编辑 + 删除自己的记录 |
| 查看者 | 仅查看，不可记账 |

### 邀请方式

| 方式 | 说明 |
|------|------|
| 邀请码 | 生成6位邀请码，对方输入加入 |
| 二维码 | 生成二维码，扫码加入 |
| 链接分享 | 生成分享链接，有效期24h |

## 页面间导航

```
我的账本 ──点击──→ 账本详情
   │                  ├──设为默认──→ 返回列表(刷新)
   │                  ├──切换账本──→ 返回列表(刷新)
   │                  ├──成员管理──→ 成员管理页
   │                  ├──分类管理──→ 该账本分类管理
   │                  ├──预算设置──→ 该账本预算设置
   │                  ├──导出数据──→ 系统分享面板
   │                  └──删除账本──→ 确认弹窗──→ 返回列表
   │
   └──点击"+新建"──→ 新建账本弹窗──→ 创建成功──→ 进入详情
```
