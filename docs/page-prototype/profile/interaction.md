# 我的 - 交互逻辑

## 页面概述

我的页面整合用户信息、功能入口和设置菜单，同时作为AI助手的入口。

## 4.3.3 功能按钮栏

### 布局

**默认状态**（每行最多5个，最后一行为"更多"）：

```
┌─────────────────────────────────────────────┐
│  🔒      🎨      📒      💰      ⋯        │
│  密码锁  主题切换 我的账本 预算管理 更多    │
└─────────────────────────────────────────────┘
```

**展开状态**（点击"更多"后显示第二行）：

```
┌─────────────────────────────────────────────┐
│  🔒      🎨      📒      💰      ⋯        │
│  密码锁  主题切换 我的账本 预算管理 更多    │
├─────────────────────────────────────────────┤
│  📂                                        │
│  分类管理                                   │
└─────────────────────────────────────────────┘
```

- 每行最多5个按钮（网格布局）
- 超过5个时，第5个为"更多"按钮
- 点击"更多"展开剩余按钮（最多2行直接展示）
- 超过10个时，点击"更多"展开完整列表
- 每个按钮：图标(44x44圆角) + 文字标签

### 交互行为

| 按钮 | 操作 | 响应 | 详情 |
|------|------|------|------|
| 密码锁 🔒 | 点击 | 进入密码锁设置页 | 设置4位数字密码 |
| 主题切换 🎨 | 点击 | 弹出BottomSheet | 亮色/暗色/跟随系统 |
| 我的账本 📒 | 点击 | 进入账本列表页 | 多账本管理 |
| 预算管理 💰 | 点击 | 进入预算管理页 | 月/周/日预算设置 |
| 分类管理 📂 | 点击 | 进入分类管理页 | 增删改排序分类 |
| 更多 ⋯ | 点击 | 进入更多页面 | 扩展功能列表 |

### 密码锁交互

| 操作 | 响应 | 详情 |
|------|------|------|
| 开启密码锁 | 设置4位数字密码 | 需确认两次 |
| 关闭密码锁 | 验证当前密码后关闭 | 二次确认 |
| 修改密码 | 验证旧密码 → 设置新密码 | - |
| App启动 | 显示密码输入界面 | 5次错误锁定5分钟 |

### 主题切换交互

```
┌─────────────────────────────┐
│  主题选择                   │

│  📱 跟随系统               │
│  ─────────────────────────  │

└─────────────────────────────┘
```

## 子页面交互

### 我的账本

| 操作 | 响应 | 详情 |
|------|------|------|
| 新建账本 | 弹出创建表单 | 名称+图标+颜色 |
| 切换账本 | 点击切换 | 刷新所有页面数据 |
| 长按账本 | 编辑/删除 | 系统默认账本不可删除 |

### 分类管理

| 操作 | 响应 | 详情 |
|------|------|------|
| 长按分类 | 进入拖拽排序模式 | 震动反馈 |
| 左滑分类 | 显示编辑/删除 | 系统分类不可删除 |
| 点击添加 | 弹出新建表单 | 图标+名称+颜色 |

### 数据备份

| 操作 | 响应 | 详情 |
|------|------|------|
| 立即备份 | 执行本地备份 | 显示进度 |
| 自动备份 | 开关切换 | 每日自动备份 |
| 恢复数据 | 选择备份文件 | 二次确认 |

### 导入导出

| 操作 | 响应 | 详情 |
|------|------|------|
| 选择时间范围 | 日期选择器 | 开始~结束 |
| 选择导出格式 | CSV / Excel | 默认CSV |
| 点击导出 | 生成文件 → 分享 | 系统分享面板 |
| 点击导入 | 选择文件 → 预览 → 确认 | 支持CSV |

### 账本回收站

| 操作 | 响应 | 详情 |
|------|------|------|
| 查看已删除记录 | 列表展示 | 保留30天 |
| 恢复单条 | 点击恢复 | 恢复到原账本 |
| 清空回收站 | 二次确认 | 不可恢复 |

### 系统设置

| 操作 | 响应 | 详情 |
|------|------|------|
| 深色模式 | 即时切换主题 | 无需重启 |
| AI服务切换 | 选择提供商 | DeepSeek / 通义千问 |
| 清除数据 | 二次确认 → 输入密码 | 不可恢复 |
| 关于 | 版本信息、隐私协议 | - |
