# 我的 - 交互逻辑

## 页面概述

我的页面整合用户信息、统计概览和设置入口，同时作为AI助手的入口。

---

## 4.3.1 用户信息卡

### 布局

```
┌─────────────────────────────────────────┐
│  👤 用户头像    用户昵称                │
│                 消费等级 Lv.5           │
└─────────────────────────────────────────┘
```

### 交互行为

| 操作 | 响应 | 详情 |
|------|------|------|
| 点击头像 | 弹出头像选择器 | 相机 / 相册 / 默认头像 |
| 点击昵称 | 进入编辑模式 | 内联编辑，最多12字符 |
| 点击等级 | 显示等级说明弹窗 | 积分规则、等级权益 |

---

## 4.3.2 统计概览

### 月度概览卡片

```
┌─────────────────────────────────────────┐
│  📊 本月统计                    < 6月 > │
│                                         │
│  总支出        总收入        结余       │
│  ¥6,540       ¥12,000      ¥5,460      │
└─────────────────────────────────────────┘
```

### 交互行为

| 操作 | 响应 | 详情 |
|------|------|------|
| 点击左箭头(<) | 切换到上一月 | 更新所有统计数据 |
| 点击右箭头(>) | 切换到下一月 | 不能超过当前月 |
| 点击月份 | 弹出月份选择器 | BottomSheet，快速跳转 |
| 点击金额数字 | 跳转到对应列表 | 如点击"总支出"→支出列表 |

## 子页面交互

### 预算设置

| 操作 | 响应 | 详情 |
|------|------|------|
| 修改总预算 | 键盘输入，实时格式化 | 保存后生效 |
| 修改分类预算 | 同上 | 不能超过总预算 |
| 超支预警开关 | 开/关切换 | 开启后超80%提醒 |

### 分类管理

| 操作 | 响应 | 详情 |
|------|------|------|
| 长按分类 | 进入拖拽排序模式 | 震动反馈 |
| 左滑分类 | 显示编辑/删除 | 系统分类不可删除 |
| 点击添加 | 弹出新建表单 | 图标+名称+颜色 |
| 点击编辑 | 弹出编辑表单 | 预填数据 |

### 数据导出

| 操作 | 响应 | 详情 |
|------|------|------|
| 选择时间范围 | 日期选择器 | 开始~结束 |
| 选择导出格式 | CSV / Excel | 默认CSV |
| 点击导出 | 生成文件 → 分享 | 系统分享面板 |

### 系统设置

| 操作 | 响应 | 详情 |
|------|------|------|
| 深色模式切换 | 即时切换主题 | 无需重启 |
| AI服务切换 | 选择提供商 | DeepSeek / 通义千问 |
| 清除数据 | 二次确认 → 输入密码 | 不可恢复 |
