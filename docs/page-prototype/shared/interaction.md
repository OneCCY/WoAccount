# 全局交互规范

## 底部导航

### 导航结构

| 位置 | Tab | 图标 | 路由 | 说明 |
|------|-----|------|------|------|
| 左 | 账单 | 📋 | /transactions | 账单列表，查看历史记录 |
| 中 | 记账 | ✏️ | / | 核心入口，记账+今日概览 |
| 右 | 我的 | 👤 | /profile | 个人信息+统计+设置 |

### 交互行为

| 操作 | 响应 | 动画 |
|------|------|------|
| 点击Tab | 切换页面，图标高亮 | 无过渡动画（NoTransitionPage） |
| 重复点击当前Tab | 回到页面顶部 | 无 |
| 记账Tab长按 | 触发语音输入（同首页记账按钮） | 震动反馈 |

### 状态保持

- 各Tab页面状态独立保持，切换不重置
- 滚动位置保持，返回时恢复
- 表单输入状态保持（如记账输入框内容）

---

## 页面转场

| 场景 | 动画 | 时长 | 曲线 |
|------|------|------|------|
| Tab切换 | 无动画 | 0ms | - |
| 进入子页面（push） | 右侧滑入 | 300ms | easeInOut |
| 返回子页面（pop） | 左侧滑出 | 300ms | easeInOut |
| 弹窗（Modal） | 底部滑入 + 背景渐暗 | 250ms | easeOut |
| BottomSheet | 底部滑入 | 300ms | easeOut |

## 通用交互模式

### 下拉刷新

- 所有列表页面支持下拉刷新
- 刷新指示器：Material Design 默认样式
- 刷新完成后显示成功提示（SnackBar，1.5s自动消失）

### 上拉加载

- 列表滚动到底部自动加载下一页
- 每页加载20条数据
- 加载中显示底部 Loading 指示器
- 无更多数据时显示"没有更多了"

### 空状态

- 无数据时显示空状态插图 + 引导文案
- 账单列表："还没有记录，去记一笔吧"
- AI对话：显示欢迎语和快捷查询

### 错误处理

| 错误类型 | 展示方式 | 操作 |
|----------|----------|------|
| 网络错误 | SnackBar + 重试按钮 | 点击重试 |
| AI解析失败 | 输入框下方提示 | 重试 / 手动记账 |
| 数据加载失败 | 页面内错误卡片 | 下拉刷新 |

### 触觉反馈

| 操作 | 反馈类型 |
|------|----------|
| 记账成功 | 轻微震动（HapticFeedback.lightImpact） |
| 删除操作 | 中等震动（HapticFeedback.mediumImpact） |
| 长按触发 | 轻微震动 |
| 语音按钮按下 | 轻微震动 |
