# AI 交互规范

## 概述

WoAccount 的 AI 能力贯穿记账全流程，从输入解析到智能分析。本文档定义 AI 相关的交互行为、状态管理和反馈机制。

---

## 1. 自然语言记账

### 输入方式

| 方式 | 触发 | 交互 |
|------|------|------|
| 文本输入 | 输入框输入 + Enter | 实时解析，显示确认卡片 |
| 语音输入 | 长按记账Tab / 麦克风按钮 | 录音 → 转文字 → 解析 → 确认 |
| 拍照输入 | 点击📷按钮 | 拍照 → OCR → 解析 → 确认 |

### 解析状态机

```
输入中 → 解析中(Loading) → 确认卡片 → 保存成功
              │                    │
              ▼                    ▼
           解析失败              修改中
              │                    │
              ▼                    ▼
          手动填写 ──────────→ 确认卡片
```

### 解析中状态

```
┌─────────────────────────────────────┐
│  🤖 AI 正在理解你的输入...          │
│  ┌───────────────────────────────┐ │
│  │  ████████░░░░  65%           │ │
│  └───────────────────────────────┘ │
│  识别中: 金额、分类、日期           │
└─────────────────────────────────────┘
```

- 显示进度动画（非真实进度，循环动画）
- 文案随机切换："正在理解..." / "马上就好..." / "AI 思考中..."
- 超过3秒显示"仍在处理，请稍候"

### 解析成功 → 确认卡片

```
┌─────────────────────────────────────┐
│  🤖 AI 解析结果                     │
│  ─────────────────────────────────  │
│                                     │
│  原始输入: 午饭拉面25               │
│                                     │
│  💰 金额:     ¥25.00               │
│  🍜 分类:     餐饮 > 午餐           │
│  📝 描述:     午饭拉面               │
│  📅 日期:     2026-06-03 (今天)     │
│  ⚡ 置信度:   92%                   │
│                                     │
│  [修改分类]  [修改金额]  [修改日期] │
│                                     │
│  [取消]              [确认记账]     │
└─────────────────────────────────────┘
```

### 解析失败

```
┌─────────────────────────────────────┐
│  😕 AI 没能完全理解                 │
│                                     │
│  请确认以下信息：                   │
```

## 2. 语音输入交互

### 录音浮层

```
┌──────────────────────┐
│                      │
│        🎤            │
│    正在聆听...       │
│                      │
│   松开发送           │
│   左上滑取消         │
│   右上滑转文字       │
│                      │
└──────────────────────┘
```

### 手势区域

```
        ┌─────────────────┐
        │   取消区(左上)   │   转文字区(右上)
        │        ↖        │        ↗
        │          ↖      │      ↗
        │            ●    │
        │          (手指)  │
        │                 │
        └─────────────────┘
              发送区(松开)
```

### 交互状态

| 阶段 | 视觉反馈 | 触觉反馈 |
|------|----------|----------|
| 按住500ms | 浮层出现 + 麦克风脉冲 | 轻微震动 |
| 录音中 | 波纹动画 + "正在聆听" | 无 |
| 松开(发送) | 浮层消失 + Loading | 无 |
| 左上滑(取消) | 浮层变红 + "松开取消" | 无 |
| 右上滑(转文字) | 浮层变蓝 + "松开转文字" | 无 |
| 录音过长(>60s) | 自动停止 + 发送 | 轻微震动 |

## 4. AI 洞察推送规则

### 触发时机

| 时机 | 洞察类型 | 优先级 |
|------|----------|--------|
| 打开App | 当日/当周洞察 | 高 |
| 记账完成后 | 实时反馈 | 中 |
| 月初 | 月度报告 | 高 |
| 预算临界(80%) | 预警 | 高 |
| 异常消费 | 实时预警 | 紧急 |

### 洞察卡片层级

```
紧急(红色边框): 异常大额、预算超标
高优(橙色边框): 预算临界、趋势异常
普通(默认样式): 趋势分析、里程碑
建议(绿色边框): 省钱建议、优化机会
```

## 6. 智能补全

### 输入时实时推荐

```
┌─────────────────────────────────────┐
│  ┌───┬─────────────────────┬───────┐│
│  │ ➕ │ 星                   │  📷  ││
│  └───┴─────────────────────┴───────┘│
│  ┌─────────────────────────────────┐│
│  │  ☕ 星巴克              餐饮/饮料││
│  │  🍜 星期一拉面          餐饮/午餐││
│  │  🛒 星期八超市          购物/日用││
│  └─────────────────────────────────┘│
└─────────────────────────────────────┘
```

### 推荐规则

| 权重 | 来源 | 说明 |
|------|------|------|
| 最高 | 历史记录完全匹配 | 相同描述的历史记录 |
| 高 | 历史记录前缀匹配 | 描述以输入开头 |
| 中 | 高频分类 | 用户常用分类 |
| 低 | 通用推荐 | 热门分类 |
