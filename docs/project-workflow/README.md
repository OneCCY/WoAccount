## 🎯 项目概述

**WoAccount** 是一个AI驱动的智能记账App，核心特点：

- **零分类操作**: 用户只需输入描述，AI自动分类
- **自然语言输入**: 支持"午饭拉面25"、"打车去公司23.5"等表达
- **AI Agent**: 支持自然语言查询、消费洞察、对话助手
- **自适应学习**: AI根据用户习惯持续优化分类准确率
- **本地优先**: 数据存储在本地，保护用户隐私

## 🔑 核心技术亮点

### 1. AI Agent 架构

```
用户输入 → 意图识别 → Function Calling → 数据查询 → 结果生成
```

- **意图识别**: LLM理解用户查询意图
- **Function Calling**: 调用预定义工具执行操作
- **上下文记忆**: 支持多轮对话
- **自然语言回复**: AI生成易读的回答

### 2. 混合分类引擎

```
输入 → 预处理 → 规则引擎 → LLM API → 结果融合
```

- **规则引擎**: 快速匹配常见模式，离线可用
- **LLM API**: 处理复杂表达，准确率高
- **结果融合**: 加权合并，取最优结果

### 3. Clean Architecture

```
Presentation → Application → Domain → Data
```

- **关注点分离**: UI、业务逻辑、数据分离
- **可测试性**: 依赖注入，易于Mock
- **可扩展性**: 模块化设计，易于扩展
