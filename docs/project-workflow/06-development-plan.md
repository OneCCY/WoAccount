## 6.8 风险与应对

| 风险 | 概率 | 影响 | 应对策略 |
|------|------|------|----------|
| AI准确率不达标 | 中 | 高 | 优化Prompt，增加规则引擎覆盖 |
| 开发进度延迟 | 中 | 中 | 优先P0任务，P2可延期 |
| 技术方案不可行 | 低 | 高 | 预留技术调研时间 |
| 需求变更 | 中 | 中 | 核心功能稳定后再加功能 |
| LLM API成本超预算 | 中 | 中 | 缓存优化，降级策略 |

## 6.9 开发规范

### 6.9.1 代码规范

```dart
// 命名规范
// 类名: PascalCase
class TransactionService {}

// 变量/函数: camelCase
final transactionList = [];
void addTransaction() {}

// 常量: camelCase (Dart推荐)
const maxRetryCount = 3;

// 文件名: snake_case
// transaction_service.dart
// transaction_list_page.dart

// 私有成员: 下划线前缀
class _PrivateClass {
  int _privateField = 0;
  void _privateMethod() {}
}
```

### 6.9.2 Git规范

```bash
# 分支策略
main          # 生产分支
develop       # 开发分支
feature/xxx   # 功能分支
bugfix/xxx    # 修复分支
release/x.x   # 发布分支

# Commit规范
feat: 新功能
fix: 修复Bug
docs: 文档更新
style: 代码格式
refactor: 重构
test: 测试
chore: 构建/工具
perf: 性能优化

# 示例
feat: 实现AI分类引擎
fix: 修复金额解析错误
docs: 更新README文档
perf: 优化数据库查询性能
```
