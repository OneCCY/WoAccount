# WoAccount UI 设计系统规范

> **版本**: v1.0 | **创建日期**: 2026-06-04 | **状态**: 已确认

---

## 1. 设计原则

| 原则 | 含义 | 应用场景 |
|------|------|----------|
| **简洁** | 去除多余元素，每个元素都有存在的理由 | 界面布局、信息展示 |
| **统一** | 字体、圆角、间距、动效保持一致 | 全局样式 |
| **层次** | 通过阴影、毛玻璃、颜色深浅表达层级 | 卡片、弹窗、导航 |
| **从容** | 动画节奏偏慢，不急躁，有仪式感 | 过渡动画、微交互 |

---

## 2. 设计风格定位

- **整体风格：** 借鉴苹果设计语言，但有自己的特色
- **设计语言：** Cupertino风格为主，融合自定义元素
- **字体选择：** 思源黑体（中文）+ SF Pro（英文）
- **图标风格：** 混合使用（未选中线性，选中填充+颜色高亮）

## 10. 动画规范

### 10.1 动画原则

- **有意义：** 动画服务于功能，不是装饰
- **有节奏：** 偏慢节奏，增加仪式感
- **有弹性：** 适当弹性效果，增加活力

### 10.2 时长规范

| 类型 | 时长 | 曲线 | 说明 |
|------|------|------|------|
| 页面切换 | 350ms | easeInOut | 从右滑入，有轻微弹性 |
| 弹窗出现 | 400ms | easeOut | 从底部滑上 |
| 列表加载 | 300ms | easeOut | 依次淡入，每项延迟50ms |
| 状态变化 | 350ms | easeInOut | 平滑过渡 |
| 微交互 | 200ms | easeOut | 按钮按压、开关切换 |

### 10.3 曲线定义

| 名称 | 曲线 | 用途 |
|------|------|------|
| easeIn | cubic-bezier(0.42, 0, 1, 1) | 元素退出 |
| easeOut | cubic-bezier(0, 0, 0.58, 1) | 元素进入 |
| easeInOut | cubic-bezier(0.42, 0, 0.58, 1) | 元素移动 |
| spring | cubic-bezier(0.34, 1.56, 0.64, 1) | 弹性效果 |

## 11. 组件规范

### 11.1 按钮

#### 主要按钮

- 圆角：12pt
- 高度：50pt
- 内边距：16pt
- 字号：17pt Semibold
- 背景：主色调
- 文字：白色

#### 次要按钮

- 圆角：12pt
- 高度：50pt
- 内边距：16pt
- 字号：17pt Semibold
- 背景：透明
- 文字：主色调
- 边框：1pt 主色调

#### 文字按钮

- 圆角：无
- 高度：自适应
- 内边距：8pt
- 字号：17pt Regular
- 背景：透明
- 文字：主色调

### 11.2 卡片

- 圆角：12pt
- 内边距：16pt
- 背景：白色
- 阴影：0 2px 8px rgba(0,0,0,0.04)

### 11.3 列表项

- 高度：自动适应内容
- 内边距：16pt
- 分割线：左侧偏移16pt，颜色 #E5E5EA
- 点击反馈：背景变 #F2F2F7

### 11.4 输入框

- 圆角：12pt
- 高度：44pt
- 内边距：16pt
- 背景：#F2F2F7
- 边框：无（聚焦时可加主色调边框）

### 11.5 底部导航栏

- 高度：83pt（含安全区域）
- 背景：毛玻璃效果
- 图标尺寸：25pt
- 文字字号：10pt
- 选中颜色：主色调
- 未选中颜色：#8E8E93
