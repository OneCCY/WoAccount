# WoAccount AI能力总览

> **版本**: v1.0 | **创建日期**: 2026-06-04

---

## 1. AI在WoAccount中的定位

WoAccount的核心差异化：**AI不是附加功能，而是记账体验本身**。

```
传统记账App：
用户 → 手动选择分类 → 手动输入金额 → 保存

WoAccount：
用户 → 输入描述 → AI自动解析 → 确认 → 保存
```

## 2. AI能力矩阵

### 2.1 输入智能化（P0）

| 功能 | 描述 | 触发方式 | 状态 |
|------|------|----------|------|
| 自然语言记账 | LLM解析自由文本为结构化记录 | 输入框输入 | MVP |
| 语音记账 | 语音识别 + LLM解析 | 长按Tab/麦克风 | Phase 2 |
| 拍照识别 | OCR + LLM解析小票 | 点击📷按钮 | Phase 2 |
| 智能补全 | 输入时实时推荐分类 | 输入过程 | Phase 2 |
| 重复检测 | 检测疑似重复录入 | 提交时 | Phase 1 |

### 2.2 智能分析（P1）

| 功能 | 描述 | 展示位置 | 状态 |
|------|------|----------|------|
| 消费洞察卡片 | 自动生成当日/当周洞察 | 首页 | Phase 2 |
| 分类趋势 | 各分类消费趋势对比 | 统计页 | Phase 2 |
| 异常检测 | 检测异常大额或频率突变 | 首页提醒 | Phase 3 |
| 月末总结 | AI生成月度消费报告 | AI助手页 | Phase 3 |

### 2.3 AI对话助手（P1）

| 功能 | 描述 | 示例 | 状态 |
|------|------|------|------|
| 消费查询 | 自然语言查询历史消费 | "上个月餐饮花了多少" | Phase 2 |
| 存在性查询 | 确认某笔消费是否发生 | "我上周剪过头发吗" | Phase 2 |
| 趋势分析 | 消费趋势对比分析 | "这个月比上个月多花了多少" | Phase 3 |
| 预算管理 | 通过对话设置预算 | "把餐饮预算改成1500" | Phase 3 |
| 消费建议 | 个性化省钱建议 | "分析一下我哪里可以省钱" | Phase 3 |

### 2.4 智能预测（P2）

| 功能 | 描述 | 状态 |
|------|------|------|
| 月末预测 | 预测本月总消费趋势 | Phase 4 |
| 预算建议 | 基于历史数据推荐预算 | Phase 4 |
| 周期识别 | 自动识别周期性消费 | Phase 4 |
| 消费健康评分 | 综合评估消费习惯 | Phase 4 |

## 3. AI处理流程

### 3.1 自然语言记账流程

```
用户输入: "昨天跟朋友吃了火锅AA制，我那份128"
         │
         ▼
┌─────────────────────────────────────────────────┐
│  Step 1: 预处理                                  │
│  - 清洗文本                                      │
│  - 提取数字                                      │
│  - 识别时间词（昨天、今天、上周）                │
└────────────────────────┬────────────────────────┘
                         │
                         ▼
┌─────────────────────────────────────────────────┐
│  Step 2: 规则引擎（快速路径）                    │
│  - 关键词匹配（"火锅" → 餐饮）                  │
│  - 模式匹配（"AA制" → 特殊处理）                │
│  - 如果命中，返回结果（置信度: 0.85）            │
└────────────────────────┬────────────────────────┘
                         │
                    未命中？
                         │
                         ▼
┌─────────────────────────────────────────────────┐
│  Step 3: LLM解析（慢速路径）                     │
│  - 构建Prompt                                    │
│  - 调用LLM API                                   │
│  - 解析JSON响应                                  │
└────────────────────────┬────────────────────────┘
                         │
                         ▼
┌─────────────────────────────────────────────────┐
│  Step 4: 结果增强                                │
│  - 匹配历史记录                                  │
│  - 金额合理性校验                                │
│  - 重复检测                                      │
└────────────────────────┬────────────────────────┘
                         │
                         ▼
┌─────────────────────────────────────────────────┐
│  Step 5: 确认卡片                                │
│  - 展示解析结果                                  │
│  - 用户可修改                                    │
│  - 确认后保存                                    │
└─────────────────────────────────────────────────┘
```

### 3.2 AI对话流程

```
用户输入: "我上周剪过头发吗？"
         │
         ▼
┌─────────────────────────────────────────────────┐
│  Step 1: 意图识别（LLM）                         │
│  - 意图: existential（存在性查询）               │
│  - 时间: 上周                                    │
│  - 关键词: 剪头发、理发                          │
└────────────────────────┬────────────────────────┘
                         │
                         ▼
┌─────────────────────────────────────────────────┐
│  Step 2: 构建查询                                │
│  - 查询本地数据库                                │
│  - 筛选条件: 日期 + 分类 + 关键词                │
└────────────────────────┬────────────────────────┘
                         │
                         ▼
┌─────────────────────────────────────────────────┐
│  Step 3: 生成回复（LLM）                         │
│  - 基于查询结果生成自然语言回复                  │
│  - "上周三你在XX理发店消费了38元"                │
└─────────────────────────────────────────────────┘
```

## 5. AI与用户反馈循环

```
用户输入 → AI解析 → 用户确认/修改 → 保存
                ↑                    │
                │                    ▼
                └────────────── AI学习数据
```

### 学习数据收集

| 数据 | 用途 |
|------|------|
| 原始输入 | 训练语料 |
| AI预测结果 | 评估准确率 |
| 用户修改 | 修正数据 |
| 是否正确 | 准确率统计 |
